Agent Name Service (ANS): standar identitas agen dari Linux Foundation

Pada 10 November 2026, Linux Foundation meluncurkan Agent Name Service (ANS) sebagai proyek resmi — standar terbuka untuk identitas, verifikasi, dan discovery agen AI yang dibangun di atas infrastruktur yang sudah dipakai web: DNS dan sertifikat X.509.

Nama agenNama yang berversi, diikat ke domain operatornya
DiscoveryInfo discovery dipublikasikan lewat DNS
LifecyclePeristiwa lifecycle tercatat di transparency log
Spesifikasi7 dokumen spesifikasi
Autentikasi antar-agenmTLS atau DPoP
Interoperabilitas awalAGNTCY Agent Directory Service & Agentic Resource Discovery (ARD)

Didukung 11 organisasi sejak Juni 2026: Cisco, Cloudflare, DigiCert, DistributedApps.ai, GoDaddy, HOL, Infoblox, Radix, Salesforce, OWASP, dan Trustmodel.ai — dengan dukungan awal di AGNTCY Agent Directory Service dan interoperabilitas dengan ARD.

Kenapa ini penting untuk halaman ini: ANS bukan framework ke-17 — ini lapisan identitas lintas-framework yang duduk di atas pilihan framework apa pun. Relevansinya paling terasa untuk interop A2A dan deployment production: sebelum agen dari organisasi berbeda saling memanggil, masing-masing pihak perlu cara standar untuk membuktikan siapa agen itu, siapa operatornya, dan apakah identitasnya masih berlaku.

Detail: ansinfo.ai · github.com/agentnameservice

Bedah framework utama

Sembilan framework utama, satu per satu

Ketuk untuk membuka detail: apa yang berubah di 2026, kekuatan, dan batasannya. Framework lain (Pydantic AI, Mastra, Claude Agent SDK, Vercel, Strands, AG2, BeeAI) diringkas setelahnya.

1 · LangGraph / LangChain

Pilihan default terkuat untuk agent stateful di produksi (Python). ~149 ribu bintang GitHub (4 Nov 2026, per promptxp.app) — ekosistem terbesar di daftar ini.
Versi (8 Nov 2026)langchain 1.4.9 · langgraph 1.2.20 · JS 1.7.2
Arsitektur3 lapis: LangChain (framework) → LangGraph (runtime graph) → Deep Agents (harness)

Yang berubah di 2026

  • LangGraph 1.2.0 (12 Mei): timeout node, error handler, RunControl, DeltaChannel beta (snapshot kini tiap 100 update, bukan 1.000, di 1.2.18), streaming v3 beta.
  • LangChain 1.4.0 (1 Sep): MCP pindah ke langchain.mcp (beta); HITL per-panggilan (14–15 Okt); blok penolakan standar / ModelRefusalError (4 Nov); tiap interrupt() dapat ID sendiri + mode resume ketat (5 Nov).
  • Deep Agents 0.7.0 (24 Jul): token input 65% lebih sedikit per putaran default. LangSmith Engine v2 (24 Sep): red-teaming & deteksi tren.

Kekuatan

Kontrol alur eksplisit dan resume setelah crash; cerita observabilitas terbaik via LangSmith (LangGraph Platform kini bernama LangSmith Deployment); integrasi terluas.

Batasan

Kurva belajar curam dan kode awal lebih banyak daripada SDK tipis; rilis mingguan dan beberapa fitur unggulan masih berlabel beta; dukungan Python 3.10 akan dihentikan di langchain-core 1.8.0 / langchain 1.5.0. Berlebihan untuk satu agent tool-calling sederhana.

Sumber: developersdigest.tech · olano.ai · garagelabstech.com · promptxp.app

2 · CrewAI

Tercepat menuju demo multi-agent yang bekerja. ~59–60,7 ribu bintang GitHub; ±552 ribu unduhan PyPI/minggu (angka Sep–Okt 2026).
Versi1.15.39 · 9 Nov 2026 (12 rilis stabil dalam 30 hari sebelumnya)
BahasaPython saja (3.10–3.13; 3.14 belum didukung)

Yang berubah di 2026

  • 1.14.0 (7 Apr): checkpointing state runtime + forking. 1.14.4 (1 Mei): Azure Responses API, tools MCP Tavily/You.com native. 1.14.7 (11 Jun): backend memory/knowledge/RAG/Flow yang bisa diganti, Snowflake Cortex.
  • Lini 1.15: scaffold JSON-first (crew.jsonc), Flows deklaratif, conversational flows stabil sejak 1.15.18, crewai eval, AgentExecutor sebagai default baru.
  • Harga AMP disederhanakan: Basic gratis (50 eksekusi workflow/bulan) + Enterprise custom (SSO/RBAC/VPC, FedRAMP High/SAM). Tier Professional self-serve lama dihentikan — daftar harga lama $99/bln–$120 rb/thn sudah usang.

Kekuatan

Model mental berbasis peran (role/goal/backstory) yang intuitif; Crews + Flows mencakup kerja otonom maupun deterministik; kuat untuk crew riset/konten/analis.

Batasan

Kontrol eksekusi kurang halus dibanding LangGraph; rilis patch pernah membawa breaking change (1.15.29 menghapus path import, baru ditandai breaking 5 hari kemudian); telemetri anonim aktif secara default (CREWAI_DISABLE_TELEMETRY=true untuk mematikan); tidak ada sandbox untuk kode buatan model; observabilitas produksi terkuat ada di balik AMP.

Sumber: agentgid.com · AgentGuides — CrewAI · anchorterminal.com · lindy.ai

3 · Microsoft Agent Framework (MAF)

Peleburan AutoGen + Semantic Kernel oleh tim yang sama. ±13,9 ribu bintang GitHub (Okt 2026) — kecil, tapi didukung Microsoft dengan LTS.
VersiPython agent-framework 1.21.0 (8 Okt 2026) · .NET Microsoft.Agents.AI 1.26

Yang perlu diketahui

  • Sep 2026: hosting AG-UI (Python stabil), provider memory Foundry/Cosmos DB (preview), CodeAct via HyperlightCodeActProvider (eksekusi kode micro-VM), channel OpenAI Responses/Telegram/A2A/MCP, ekstensi Durable Azure Functions.

4 · OpenAI Agents SDK

SDK vendor paling ramping. Dirilis 11 Mar 2025 sebagai penerus produksi Swarm; ±31 ribu bintang GitHub (Okt 2026, per geekflare.com).
Versi0.24.0 · 15 Okt 2026 (masih 0.x)
OrkestrasiHandoff (triage → spesialis) & agents-as-tools — tanpa graph engine

Yang berubah di 2026

  • 15–16 Apr 2026: eksekusi sandbox native / harness model-native. Manifest membuat workspace portabel lintas penyedia sandbox — E2B, Modal, Docker, Daytona, Cloudflare, Blaxel, Runloop, Vercel (+ Unix-local untuk dev); kapabilitas Filesystem, Shell, Compaction, Memory. Laporan menyimpulkan: perlakukan sebagai OpenAI-first, kompatibel LiteLLM — verifikasi routing non-OpenAI sebelum berkomitmen. Durabilitas juga lebih tipis (via wrapper Temporal, bukan bawaan).

Sumber: agentgid.com · solosoft.dev · codex.danielvaughan.com

5 · Google ADK 2.0

Satu-satunya framework besar dengan 5 bahasa first-party. ±22 ribu bintang GitHub (adk-python); ±2,9 juta unduhan PyPI+npm dalam pekan yang berakhir 8 Nov 2026.
VersiPython 2.14.0 · 7 Nov 2026 — diverifikasi langsung di adk.dev
Pergeseran 2.0Dari executor hierarkis → graph-based Workflow Runtime

Yang berubah di 2.0 (terverifikasi langsung)

  • Workflow Runtime menilai Agents, Tools, dan Functions sebagai node dalam graph: routing, fan-out/fan-in, loop, retry, workflow bersarang; workflow dinamis (logika berbasis kode); workflow kolaboratif; Task API untuk delegasi antar-agent terstruktur dengan HITL multi-turn.
  • SequentialAgent/ParallelAgent/LoopAgent deprecated (masih berfungsi). Ada breaking change pada API agent, model event, dan skema session — migrasi dari 1.x diperlukan.
  • A2A native (ekspos agent sebagai server A2A, konsumsi peer A2A sebagai sub-agent), McpToolset, adapter LangchainTool/CrewaiTool, Vertex AI Memory Bank, eval bawaan, UI dev adk web.

Kekuatan

Cerita Google Cloud terlengkap; dipakai internal di Google (Agentspace) sebelum open-source; graph runtime + A2A/MCP native.

Batasan

Tool Confirmation masih eksperimental dengan celah yang diketahui — jangan andalkan sendirian untuk aksi destruktif/finansial. Paritas bahasa tertinggal (fitur mendarat di Python dulu). Klaim breaking change di rilis minor 2.x dan CVE — lihat bagian “belum terverifikasi”.

Sumber (langsung): adk.dev/2.0 · agentgid.com · atlan.com

6 · LlamaIndex + Workflows 1.0

Terbaik di kelasnya untuk dokumen berantakan dan agent berat retrieval. ±52,8 ribu bintang GitHub (4 Nov 2026).
Versillama-index-core 0.14.25 · 21 Sep 2026 (masih 0.x)

Yang berubah di 2026

Paket Starter $50/bulan (40.000 kredit) sudah tidak ditawarkan ke pelanggan baru. Angka $5.000 yang sempat beredar adalah batas pay-as-you-go Pro, bukan harga paket.

Sumber (langsung): llamaindex.ai — Workflows 1.0 · promptxp.app

9 · Tema lintas-framework 2026

Tiga hal yang kini menentukan pilihan — bukan lagi dukungan protokol.
  • MCP + A2A sudah universal. Pilihan framework kini lebih soal model kontrol dan ekosistem daripada dukungan protokol.
  • Differentiator produksi: eksekusi durable + sandboxing + persetujuan HITL. Contoh 2026: checkpointing LangGraph/CrewAI/MAF/LlamaIndex, durable Pydantic AI Harness di 8 engine, WorkflowAgent di Vercel AI SDK 7 / Eve.
  • SDK vendor kini framework yang kredibel (OpenAI, Google, Anthropic) — terbaik di dalam stack model/cloud-nya sendiri, terlemah di luar itu.
  • Riset State of Agent Engineering dari LangChain (dikutip tangan kedua dalam laporan): 57% organisasi menjalankan agent di produksi; hambatan utama adalah kualitas output, bukan biaya.

Rekomendasi

Pilih berdasarkan kebutuhan, bukan popularitas

Empat skenario dari laporan — enterprise, prototyping, kolaborasi multi-agent, dan deployment produksi.

🏢 Enterprise

Governansi, audit, dukungan, dan kesesuaian cloud.

  • .NET / Azure → MAF. LTS, Foundry, OTel, MCP/A2A, jalur migrasi SK/AutoGen. Semantic Kernel hanya jika sudah terlanjur investasi — rencanakan migrasi sebelum lantai dukungan Apr 2027.
  • Google Cloud / Gemini → Google ADK 2.0 + Vertex AI Agent Engine — tapi kunci (pin) versi dan siapkan anggaran untuk breaking change di rilis minor.
  • AWS → Strands Agents (ramping, Bedrock AgentCore) atau LangGraph yang di-host di AWS.
  • Vendor-neutral / teregulasi / self-hosted → LangGraph atau Haystack (pipeline serial yang bisa ditinjau — cerita governansi RAG terkuat).
  • Hindari untuk build enterprise baru: AutoGen, Semantic Kernel (maintenance), AG2 Classic.

⚡ Prototyping

Tercepat menuju demo yang bekerja.

  • Demo multi-agent dalam hitungan jam → CrewAI (roles/goals/backstory + Flows). Waspadai breakage di rilis patch.
  • Agent tunggal, OpenAI → OpenAI Agents SDK — primitif paling sedikit, tracing sudah termasuk.
  • Agent tunggal, Claude → Claude Agent SDK — tools file/shell/web bawaan, boilerplate nyaris nol.
  • Prototipe Python type-safe yang harus jadi layanan → Pydantic AI.
  • Prototipe TS/React → Vercel AI SDK 6/7 (ToolLoopAgent).

🤝 Kolaborasi multi-agent

Tim agent, delegasi, debat, dan interop.

  • Tim berbasis peran / delegasi → CrewAI (crews + proses hierarkis) atau MAF (workflow handoff / group-chat / Magentic).
  • Debat percakapan / group chat → AG2 v1.0 (Network bertipe) — terima biaya penulisan ulangnya — atau group chat MAF.
  • Agent lintas-framework / lintas-organisasi → Google ADK (A2A + MCP native) atau BeeAI (ACP). A2A adalah taruhan interop 2026 — dan sejak 10 Nov 2026, lengkapi dengan Agent Name Service (ANS) untuk identitas, verifikasi, dan discovery agen lintas organisasi (lihat update ANS).
  • Orkestrasi tim yang eksplisit & bisa diaudit → LangGraph (subgraph, shared state, interrupts) — kontrol terbanyak, kode terbanyak.

🚀 Deployment produksi

Durable, terobservasi, dan terkendali biayanya.

  • Berjalan lama / bisa resume setelah crash → LangGraph (checkpointer, DeltaChannel, LangSmith Deployment) — cerita terkuat. Setara bertipe/TS-nya: Pydantic AI Harness (8 engine durable termasuk Temporal/DBOS) dan Mastra (suspend/resume + Platform); Vercel Eve jika TS + filesystem-first dan pra-GA bisa diterima.
  • Eksekusi kode tersandbox → OpenAI Agents SDK (sandbox Manifest multi-penyedia) atau MAF CodeAct/Hyperlight; code_execution ADK untuk Gemini.
  • Kematangan observabilitas/eval: LangSmith (LangGraph), Logfire (Pydantic AI), eval Mastra, eval bawaan ADK, tracing dashboard OpenAI — pilih cerita tracing bersama framework-nya, bukan sesudahnya.
  • Produksi berat dokumen → LlamaIndex Workflows + LlamaParse, atau pipeline Haystack 3.0.
Kejujuran riset

Yang belum terverifikasi — jangan kutip sebagai fakta

Pertanyaan terbuka dari laporan (10 Nov 2026)

  • “LangGraph 2.0” (Feb 2026) — TIDAK BENAR: lini Python terverifikasi tetap 1.2.x — 1.2.20 per 5 Nov 2026 (PyPI, dicek 10 Nov 2026); JS 1.7.3 dan langgraph-sdk 0.4.14 bukan 2.0. Klaim dev.to tersebut tidak dipakai.
  • Nama model di sumber sekunder 2026: beberapa panduan menyebut “GPT-6 / gpt-6-luna / gpt-5.6-luna” sebagai default CrewAI/OpenAI. Tidak bisa diverifikasi terhadap daftar model resmi dan tampak seperti konten sintetis/bertanggal masa depan — tidak diulang di sini sebagai fakta.
  • CVE Google ADK — SEBAGIAN TERVERIFIKASI (11 Nov 2026): CVE-2026-18236 (CVSS 9.3, kritis) memungkinkan pemalsuan konfirmasi tool lewat manipulasi riwayat sesi, ADK Python <2.5.0, GHSA-8qg5-x5vm-75jx; plus CVE-2026-115522 (isolasi artifact antar-aplikasi, diperbaiki 2.7.0/1.39.1), CVE-2026-107858 (Java, CVSS 7.2, diperbaiki 1.13.0), dan CVE-2026-105772 (TypeScript path traversal, diperbaiki 0.6.0). Total 4 CVE 2026 yang terdokumentasi sejauh ini — angka “6 CVE, 3 kritis” belum terkonfirmasi. Pin ADK Python >=2.7.0; versi 2.14.0 di halaman ini sudah di atas semua perbaikan tersebut. Klaim breaking change minor 2.x dan hapus Python 3.10 di 2.12.0 masih belum terverifikasi.
  • Harga LlamaParse — terkoreksi 11 Nov 2026: terverifikasi dari dokumen resmi LlamaIndex (Nov 2026): gratis $0/bulan (10.000 kredit) dan Pro $500/bulan (400.000 kredit, $1,25 per 1.000 kredit tambahan). Starter $50/bulan (40.000 kredit) sudah tidak ditawarkan ke pelanggan baru, dan angka $5.000 adalah batas pay-as-you-go Pro — bukan harga paket. Konflik harga antar sumber sekunder sebelumnya kini terselesaikan.
  • Cakupan provider OpenAI Agents SDK: posisi resmi (provider-agnostic via LiteLLM) vs sebagian ulasan (OpenAI-only) bertentangan — verifikasi routing non-OpenAI di dokumentasi terkini.
  • Status LlamaIndex TS: satu sumber menyebut port TS diarsipkan pada 2026, sementara paket Workflows TS (@llamaindex/workflow-core) masih mutakhir — cakupan pengarsipannya belum jelas.
  • Bintang Hermes Agent — terkoreksi 11 Nov 2026: klaim ±220 ribu bintang per Jul 2026 kini didukung pemeriksaan API GitHub independen (±247.700 pada 21 Sep 2026; ±252.576 pada 10 Okt 2026; 257.311 bintang / 56.367 fork pada 26 Okt 2026; rilis v0.22.5 pada 23 Okt 2026; repo dibuat 22 Jul 2025, rilis publik pertama v0.2.0 pada 12 Mar 2026). Angka bintangnya kini terverifikasi — tetapi bintang tetap bukan bukti kesiapan produksi, jadi Hermes tetap di daftar pantau.
  • Angka bintang/unduhan (LangChain 149 rb, CrewAI ±60 rb, MAF ±14 rb, Mastra 22–26 rb, unduhan npm 300 rb–1,1 jt/minggu) adalah snapshot dari tanggal/sumber berbeda dan saling bertentangan — pakai hanya sebagai sinyal ekosistem kasar.
  • Cakupan verifikasi langsung: halaman resmi hanya diambil live untuk ADK 2.0, LlamaIndex Workflows 1.0, dan Haystack 3.0; nomor versi lain bertumpu pada pencarian indeks (beberapa sumber sekunder yang sepakat + pelacak turunan PyPI/GitHub), bukan pembacaan live GitHub/PyPI dalam sesi riset ini.
